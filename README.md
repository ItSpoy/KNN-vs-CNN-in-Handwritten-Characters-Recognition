Comparaison : CNN vs 3 Approches Optimisées du KNN

Ce projet a pour objectif de réaliser une étude comparative entre les réseaux de neurones convolutifs (CNN) et trois approches optimisées de l’algorithme K-Nearest Neighbors (KNN) dans le cadre de la reconnaissance de caractères manuscrits.

- Les Objectifs :

	CNN (Convolutional Neural Network)
	KNN Standard optimisé
	KNN avec réduction de dimension (PCA)
	KNN avec optimisation des distances / paramètres
- Les Résultats :

	Chaque approche a été évaluée selon plusieurs critères :
	. Accuracy (précision)
	. Temps d'entraînement et de prédiction
	. Robustesse du modèle
